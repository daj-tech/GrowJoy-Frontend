# GrowJoy — Plant Care & Gamification Website

**Make Every Plant Grow with Joy**

GrowJoy is a frontend prototype that makes plant care easier and more engaging. It helps users explore plants, learn how to care for them, track their progress, and enjoy care activities and rewards.

## Features

- **Landing page** introducing GrowJoy and its features
- **Login page** with a user login interface
- **User dashboard** showing plants, care tasks, growth progress, and Care Coins
- **Growing conditions form** for entering plant-growing conditions and preferences
- **Plant recommendations** with sunlight, watering, and difficulty information
- **Care activities and rewards** with growth tracking, photo-submission options, and achievement badges

## Technologies

- HTML5
- CSS3

## Project Structure

Each website page is organized in its own folder with its related HTML and CSS files. Images, icons, and other assets are stored in their respective folders.

Keep the original folder structure so that styles and assets load correctly.

## Run the Project

1. Download or clone the GrowJoy repository.
2. If you downloaded a ZIP file, extract it.
3. Open the project folder.
4. Open the folder for the page you want to view.
5. Open that page’s HTML file in a web browser.

## Project Scope

This repository contains the frontend interface for GrowJoy. Real user authentication, database storage, task verification, and persistent reward updates require backend functionality unless implemented separately.
