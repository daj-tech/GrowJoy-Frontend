# GrowJoy — Plant Care & Gamification Website

**Tagline:** Make Every Plant Grow with Joy

## About the Project

GrowJoy is a frontend website project designed to make plant care easier and more engaging. It helps users explore suitable plants, understand their care requirements, track their plant journey, and experience gamification through care activities and rewards.

## Features

- **Landing Page:** Introduces GrowJoy and its main features.
- **Login Page:** Provides the user login interface.
- **User Dashboard:** Displays plants, care tasks, growth progress, and Care Coins.
- **Growing Conditions Form:** Collects the user's plant-growing conditions and preferences.
- **Plant Recommendations:** Displays suitable plants with their sunlight, watering, and difficulty information.
- **Plant Care Activities & Rewards:** Presents care tasks, growth tracking, photo-submission options, and achievement badges.

## Technologies Used

- HTML5
- CSS3

## Project Folder Structure

Each website page is organized into its own folder containing the relevant HTML and CSS files. Images, icons, and other assets are stored in their respective folders.

## How to Download and Run the Project

1. Open the GrowJoy-Frontend GitHub repository.
2. Download the `GrowJoy.zip` file.
3. Extract the ZIP file on your computer.
4. Open the extracted GrowJoy project folder.
5. Open the folder for the page you want to view.
6. Double-click the HTML file to open that page in your web browser.

**Note:** Keep the project's original folder structure so that CSS files, images, and other assets load correctly.

## Project Scope

This repository contains the frontend interface of GrowJoy. Features such as real user authentication, database storage, task verification, and persistent reward updates require backend functionality unless separately implemented.
